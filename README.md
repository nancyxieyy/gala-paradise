# 旮旯乐园 · Gala Paradise

macOS / Windows 卡通桌宠。旮杂在窗口边缘出没；你可以养熟几位住客，也可以请老鼠、猫咪帮忙守住桌面。

## 1.5 · 住客与支线内测版

这一版把[玩法设计草案](Docs/玩法与支线设计草案.md)接成可玩的基础循环。主面板与菜单栏／系统托盘新增 **「住客手册」**，两端使用相同规则。

![住客手册](Resources/life-preview.png)

| 玩法 | 当前可玩的内容 |
| --- | --- |
| 个体关系 | 熟悉的住客保留身份；召回、抚摸、投喂、命名、结为伙伴；逃脱会增加警惕，靠近时会躲开 |
| 伙伴支线 | 旮杂室友、老鼠巡逻员、猫咪守护者；最多 6 位伙伴，多条线可以同时走 |
| 保护与共居 | 命名、伙伴或领养即受保护；左半屏安全窝、右半屏巡逻；两种伙伴可安排共居 |
| 收纳 | 主动提交文字、链接、待办；纸条列表、复制取回、完成标记与删除；动物离开仍可取回 |
| 痕迹探索 | 活跃生态约 60 秒后留下可点击的金色碎屑；追踪后发现黄金旮杂的小窝 |
| 专注约定 | 1–120 分钟计时，默认 25 分钟；计时期间隐藏住客与痕迹、停止随机事件，完成获成就 |
| 好友领养 | 离线 `GALA1:` 领养码，Mac／Windows 通用；发送方保留住客，接收方得到受保护的新个体 |
| 成就卡册 | 22 个里程碑，按成功事件记录日期，不连发弹窗，不继承他人的成就 |

### 从哪里开始

1. 打开应用，点「撒点面包屑」邀请旮杂，再打开「住客手册」。
2. 在住客列表选一位。点「摸一摸」或「喂一口」；每 20 秒可发生一次有效关系互动。信任达到 6 后可点「成为伙伴」。名字通过上方输入框填写，再点「取名字」。
3. 信任达到 2 后，可把文字／链接／待办填进输入框，点「收好输入内容」。纸条一直保存在手册中，不必等动物出现。
4. 内测时长沿用老鼠 3 分钟、猫咪 10 分钟门槛，暂停、离线、计时专注不增加发现时长。老鼠最多同时两只，猫爪最多一只；熟悉个体会重复来访。
5. 老鼠或猫成为伙伴后，选择它并点「请伙伴巡逻」：右半屏安静 60 秒，驱赶普通旮杂；实际赶到目标才计入巡逻／守护成就。伙伴不会替你刷击杀或金壳。
6. 两种伙伴可点「安排共居」，建立左侧安全窝并分别出场；已命名的旮杂即使走出安全区也受到保护。
7. 分享住客前先命名或培养为伙伴。「生成领养码」把码复制到剪贴板，自己发送给朋友；朋友粘进输入框后主动接收。相同码在同一存档只接收一次。

### 关系、保护与黄金卵壳

- 基础抚摸、投喂、命名、专注和成就查看免费。工具仍用黄金卵壳兑换，旧存档已解锁的工具保留。
- 命名／伙伴／领养保护随个体生效。伤害工具与游戏扫描不会永久伤害它们；开启安全窝后，左半屏的其他住客也受区域保护。
- 黄金旮杂可通过捕获或友好方式收获。友好方式要求信任达到 2，再点「友好取金壳」。每个身份只给一次 **2 枚黄金卵壳**，之后还能继续做朋友。
- 已收获的黄金住客不挡住后续黄金访客；领养黄金住客不额外产生金壳。
- 专注期间仍能管理纸条；动物召回、探索等互动暂停。隐藏桌宠不停止计时，关闭应用会取消未完成计时，不补发完成奖励。中途结束不扣关系。
- 同一动作不会既算抚摸又算伤害。与动物互动请用手册里的明确按钮；主工具箱的「捏一下」仍是应对工具。

### 首批成就

首次／三次击败、首次黄金收获、初遇老鼠／猫、抚摸老鼠／猫、旮杂／老鼠／猫成为伙伴、第一次给旮杂命名、第一次投喂、首次收纳／取回、追踪脚印／发现窝、巡逻／守护、共居、完成专注、领养入住、生成领养卡。

击败统计只算成功击败的活体：击空、飞走、吸尘、重复处理尸体、伙伴驱赶和后台扫描不算主动击败。命名和伙伴关系不重复发卡；旧存档不根据当前尸体倒推历史击杀。

### 当前边界

这是支线机制的首轮可玩版本，入口集中在住客手册。当前探索场景是金色碎屑与小窝；更丰富的分支对白、头盔装扮、猫鼠追逐、卡面插画与领养故事字段仍在设计草案中，尚未制作。区域暂为屏幕左右半区，不能自由绘制。

收纳只处理主动输入的内容，不后台读取剪贴板、文件正文或打字内容。内容以本地存档保存，不上传；目前是普通 JSON，未提供加密。领养码只包含格式版本、领取标识、物种、名字，不含纸条、路径、资源、信任或成就；它是离线游戏数据，**不具有服务端身份验证或防篡改认证**。没有自动发送给朋友的行为。

## 桌面生态与清洁工具

![角色预览](Resources/new-friends.png)

- 普通旮杂尺寸 68，幼体 45，老鼠 170，猫爪 240。猫爪从边缘伸入、爪背朝上落在桌面上，再抬起收回，完整动作约 6 秒。
- 住客从屏幕或文件夹窗口边缘出现，再躲起来。屏幕暂时完全没有住客是正常的。
- 文件夹联动仅记录应用观察到的进入／切换事件。经常访问少出虫，闲置逐渐恢复；关闭联动仍可玩完整的基本支线。
- 生长速度 0.25×／1×／3×只影响繁殖和孵化。旧「专注模式」是生态安静开关；新手册中的计时专注额外提供倒计时和完成成就。
- 「杀毒扫描」只清理游戏住客，不是真实杀毒或电脑清理程序。污渍是透明窗口图形，不会修改真实桌面文件。

| 工具 | 金壳价格 | 行为 |
| --- | ---: | --- |
| 捏一下 | 免费 | 击败普通旮杂，留下奶油污渍 |
| 人字拖 | 2 | 拍打；飞行中的目标可能逃脱 |
| 蟑螂药 | 4 | 文件夹出虫投药与游戏扫描；不处理真实文件 |
| 吸尘器 | 6 | 吸走未受保护的旮杂、尸体和卵 |
| 清洁剂 | 5 | 擦除游戏污渍 |

## 运行与朋友测试包

- Mac：macOS 13+，Universal 包支持 Apple Silicon / Intel。
- Windows：Windows 10 22H2 / Windows 11 x64，自带 .NET 运行时。
- 主窗口收起后，Mac 顶部蟑螂图标、Windows 右下角托盘图标仍可打开手册、切换工具和退出。
- 朋友包在 `releases/GalaParadise-1.5-macOS-Universal.zip` 与 `releases/GalaParadise-1.5-Windows-x64.zip`，附说明、反馈模板和 SHA-256 校验文件。
- 更新时先退出旧进程，再打开新版。朋友包不附带开发者存档。
- Mac 本机模型／原生集成检查通过；Intel 为交叉构建。Windows 模型检查与 x64 编译通过，托盘、DPI 和新手册仍需 Windows 真机验收。未配置正式发行签名／Mac 公证。

## 开发与验证

Mac 需要 Xcode Command Line Tools；Windows 项目使用 .NET 10 SDK。

```sh
./build.sh
'build/旮旯乐园.app/Contents/MacOS/GalaParadise' --integration-test
'build/旮旯乐园.app/Contents/MacOS/GalaParadise' --render
# 有 dotnet 命令时：
dotnet run --project Tests/CoreTests -c Release
./package-release.sh
```

`build-release.sh` 支持 `GALA_DOTNET` 指定 SDK 路径，并在无系统 dotnet 时使用本项目已有的 `build/toolchain/dotnet/dotnet`。构建目录与发行 ZIP 不提交 Git。

主要模块：

- `Sources/Life.swift` / `Windows/Life.cs`：个体档案、一次性事件、关系、收纳、专注、离线领养。
- `Sources/LifeUI.swift` / `Windows/LifeUI.cs` / `Windows/LifeActions.cs`：住客手册与支线操作。
- `Game`、`Progression`、`Habitat`：玩法、道具与文件夹生态。
- `Sources/App.swift` / `Windows/Desktop.cs`：原生窗口、托盘、桌面调度。
- [验证记录](Tests/VALIDATION.md)、[朋友测试说明](Docs/朋友测试说明.txt)、[设计草案](Docs/玩法与支线设计草案.md)。

存档：Mac `~/Library/Application Support/GalaParadise/save.json`，Windows `%LOCALAPPDATA%/GalaParadise/save.json`。关系、纸条和卡册随存档保存，未完成专注不会在重新启动后计为完成。旧版数据缺少新字段时初始化空的住客手册，保留原有进度与工具。
