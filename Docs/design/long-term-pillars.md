# 长期可玩的支柱（草案，待负责人选择）

> 状态：草案 · 2026-10-28 · Claude
> 参考框架：玩家旅程（头 5 分钟 → 第一周 → 长期）、资源来源与消耗。来自 Claude Code Game Studios 的模板，按本项目的实际情况裁剪。

## 一句话定位

**一个你不用照顾、但每次回来都有变化的小世界。** 它尊重你的忙碌：忙的时候不出来添乱，闲下来时给你一点惊喜。它会记住你怎么对待它，并且因此改变。

## 目标玩家

上班族，主要在电脑前工作，注意力是稀缺资源。他们不会为游戏专门腾出时间，但愿意在等编译、开会间隙、下班前瞥一眼。他们讨厌被打断，喜欢「不用管也没关系」的陪伴。参照物是《旅行青蛙》和 Neko Atsume（猫咪后院）：异步、低压力、回来就有发现。

## 现在为什么玩不久

现在的核心动作是「打 / 清理 / 喂」，几分钟就能摸透。生态模拟其实很深，但玩家看不见它的深度：事件发生在你没看的时候，而且没有任何东西帮你回顾。同时，玩家的行为对世界没有长期影响，打掉的就没了，世界不会因为你而变化。

## 候选支柱

每条都标了它和现有代码的距离：**近**是指已有的字段或系统可以直接延伸。

### P1 不打扰（D6，已定方向）

你忙时，它们在角落里繁衍得更快，但藏着不出来；你闲下来，或者打开很久没碰的文件夹时，它们再陆续出来。

- 「忙」的判断建议综合几项，不只看 GPU：
  - 只看 GPU 会误判：写文档时 GPU 很闲，看视频时 GPU 很忙但人很闲。
  - 电脑负载（CPU / GPU 占用）；
  - 你操作的频率（只看「距离上次操作多久」，不读按键内容）；
  - 前台是否是全屏应用（比如在开会、做演示）。
- 隐私：只读系统总负载和空闲时长，不记录应用名、不读按键，和现有隐私原则一致。
- 「出来」要有节奏：闲下来后一只一只陆续出现（例如每 20 秒最多一只），不能一下子涌出一大群。
- 打开很久没碰的文件夹会惊动藏在那里的一窝。这正好接上现有的「文件夹 = 栖息地」机制：越久不碰的地方，越可能藏着一个大家族。
- 距离：中。生长倍率和可见预算都已有；需要新增系统负载读取（Mac 用 IOKit，Windows 用性能计数器）。

### P2 回来有惊喜：旮旯日报

当你从忙碌中抬头（或者每天下班前），小窝里有一张「今天角落里发生了什么」的短卡片：

- 「下载文件夹里的老家族孵出了 6 只，其中一只是金色的。」
- 「你上午喷过药的地方，现在一只都不剩了。」
- 「一只叫豆豆的住客搬去了归档文件夹。」

- 内容全部来自真实的生态事件日志，不编造、不写剧情，和项目的「不写剧情脚本」原则一致。
- 它解决的问题是：生态的深度发生在你没看的时候，日报把这些深度交还给你。
- 和 P1 配合最好：忙时发生的事，闲时用日报讲给你听。
- 距离：近。事件日志、栖息地、个体身份都已有，主要是挑选和文案。

### P3 它们因你而变：遗传与进化

每只住客已经有胆量、好奇、抗药性、繁殖力这些性格数值，只是现在是随机生成的。改为**由父母遗传，并带一点随机变异**：

- 你常喷药 → 活下来的都是抗药的 → 几代之后，你的桌面上住着一群「药都不怕」的家族。
- 你常喂、常摸 → 胆大亲人的家族繁衍得更好 → 它们会主动靠近鼠标。
- 你常用拖鞋 → 会飞会躲的个体留下来 → 越来越难打。

- 你的玩法塑造了你的世界，每个人的桌面都长得不一样，这是真正的长期动力。
- 完全是规则自然组合出来的结果，没有剧情脚本。
- 配一个「家谱」页面，能看到某只住客往上几代、哪个家族最兴旺。卵的父母信息现在已经在记录了（`originEgg`）。
- 距离：近到中。性格字段和亲代记录都已存在；需要做双端同步、平衡实验和家谱界面。

### P4 经营角落：小摆设

用金壳在桌面角落放小摆设：一个小纸箱窝（更适合筑巢）、一盏小灯（让那里不容易藏身）、一个小风扇（赶它们走）、一碟糖（吸引）。

- 给「喜欢养」和「不喜欢它们」的玩家各自一条长期路线（现有设计草案第 8 节提到过这两类玩家）。
- 金壳有了持续的消耗渠道，不再买完工具就没用了。
- 摆设只改变栖息地参数，生态结果仍然由规则决定。
- 距离：中。栖息地参数已有；需要新的桌面物件、放置交互和商店。

### P5 收集与交换

图鉴（颜色变异、金色、稀有访客、每个家族的「代表」）加上用现有领养码和朋友交换住客，带着它的家族性格过去。

- 距离：近（领养码已存在），但它更依赖 P3 先让个体变得有差异。

## 建议

**第一批做 P1 + P2，第二批做 P3。**

- P1 和 P2 一起，构成「忙时不打扰、闲时有惊喜」的完整循环，直接回应上班族的处境，而且主要复用已有系统。
- P3 是让人玩几周、几个月的核心，但需要先有 P2 这样「看得见变化」的渠道，否则玩家感觉不到进化。
- P4、P5 依赖前面的支柱，放到后面。

## 每个阶段玩家应该感受到什么

| 阶段 | 玩家在问 | 应该得到的体验 |
| --- | --- | --- |
| 头 5 分钟 | 这是什么？会烦我吗？ | 一两只小东西在角落探头，被点了会有反应；没有教程弹窗 |
| 第一天 | 它们在干嘛？ | 下班前看到第一张日报：「原来我忙的时候发生了这么多」 |
| 第一周 | 我做的事有影响吗？ | 发现常去的文件夹没虫、闲置的文件夹藏着一窝；尸体不收拾会招来更多 |
| 第一个月 | 我的世界和别人的有什么不同？ | 家族有了自己的性格（因为你的打法）；家谱里有了第一位「老祖宗」 |
| 长期 | 还有什么新鲜的？ | 稀有变异、和朋友交换住客、给角落添置摆设 |

## 需要负责人决定

1. 认可「第一批 P1 + P2，第二批 P3」吗？还是想换顺序或换支柱？
2. P1「忙」的判断：同意综合负载 + 操作频率 + 全屏，而不只看 GPU 吗？
3. 日报出现的时机：每天固定时间（比如下午 6 点）、每次从忙碌转为空闲时，还是只在你打开小窝时？
