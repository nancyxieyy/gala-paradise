# Emergent World V0 — 实验结果

2026-09-11，版本 1.7.0。Apple Silicon 开发机，完全离线的 Swift / C# 模拟。下列时间均为模拟活跃秒数，不是真实等待时长。所有主场景 seed = 42；不是精选多个种子里最好看的结果。

## 1. What changed

新增 World、WorldBridge 和头部无界面的 Simulation harness。Mac / Windows 两份同规则实现，拥有相同的持久化生态字段、32 位 LCG、2 秒步长、稳定迭代顺序和事件序号。通过完整世界、每条事件和每分钟样本的跨语言比较，约束实现漂移。

World 负责生态身份、阶段、需求、位置、巢穴、药剂与行为。Life 仍独立拥有关系、纸条、领养和成就；Resident 作为原生图层／直接工具操作的兼容投影保留。明确工具结果由 bridge 协调回 World；World 产生的阶段、孵化与可见意图投影回桌面，不运行第二套旧生态计时器。

没有增加动物、成就、页面、云服务或模型调用。旧存档迁移不产出历史事件或补发成就；导入当前个体与已有关系。生态年龄从当前阶段开始，不根据旧 wall clock 补算离线孵化。

## 2. World Model

世界保存：seed / PRNG state、生态时间、容量、栖息地、个体、玩家交互计数、活动强度、待处理信号、访客冷却、有限事件环与统计。

个体：身份、阶段、年龄、饥饿、能量、恐惧、好奇、胆量、繁殖倾向、信任投影、保护标记、威胁／友好／位置记忆、剂量与耐受度、抽象距离、意图、出入位置和冷却。巢穴是栖息地上的状态；卵作为有独立孵化年龄的实体。

| 规则 | 实际作用 |
| --- | --- |
| 扰动 | 访问增加扰动／活动，安静时衰减 |
| 栖息偏好 | 比较食物、安静、可筑巢程度、药剂、压力、位置记忆；足够更好时迁移 |
| 成巢 | 至少两个住客、位置稳定、可筑巢时随机形成 |
| 生命周期 | 稳定窝中吃饱的可繁殖成虫概率产卵；卵孵化、幼体成熟，成熟时有稀有金色概率 |
| 药剂 | 残留衰减；按抽象距离、耐受、暴露累积剂量；保护优先；卵减慢孵化 |
| 种群压力 | 局部密度增加竞争、迁移、活动和成巢机会；总容量限制繁殖 |
| 个体记忆 | 攻击／友好信号改变后续 utility，威胁缓慢衰减 |
| 食物 | 游戏内投喂与清理改变食物，进食消耗食物并恢复个体状态 |
| Utility | flee / hide / freeze / eat / rest / explore / approach / nest / idle 竞争 |
| 生态访客 | 活动、玩家历史、稀有权重与冷却决定猫鼠来访；来访增加未保护旮杂的警觉 |

Director 只返回压力、稀有度、紧张度三个参数；不输出角色台词、剧情编号或行为脚本。

## 3. Removed fixed triggers

移除了打开文件夹固定生成若干住客、喂食直接生虫、周期产卵、清空后 24 秒补幼体、固定黄金访客、3 分钟老鼠、10 分钟猫、60 秒碎屑生成黄金住客、旧的即时药剂死亡与平台自带年龄升级。

内部关系门槛、工具价格、防连点奖励冷却与显示停留时间仍保留。界面不再展示信任 2 / 6 或猫鼠分钟倒计数。短暂显示／空白间隔属于表现预算，不决定生态出生。鼠标飞行躲避的原有工具随机数仍在兼容交互模型中，未纳入生态重放保证。

## 4. Emergent findings

### 实测汇总

| 场景 | 时长 | 最终活体旮杂 | 卵 | 巢穴 | 累计死亡 | 迁移 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| A 高频 Downloads | 30 分钟 | 36 | 0 | 1 | 0 | 22 |
| B 闲置 Archive | 30 分钟 | 24 | 2 | 2 | 0 | 8 |
| C 药剂冲击 | 30 分钟 | 31 | 0 | 2 | 5 | 17 |
| D 清掉成虫，保留卵 | 30 分钟 | 12 | 1 | 2 | 6 | 10 |
| E 胆大／胆小 | 1 分钟 | 2 | 0 | 0 | 0 | 2 |
| F 反复喂食／喷药 | 2 小时 | 14 | 0 | 2 | 20 | 251 |
| G 长期运行 | 1 天 | 32 | 0 | 1 | 0 | 18 |

这里的活体数量不包含猫鼠；访客是事件输出，原生端复用已有身份且限量展示。Births 统计新建生态实体，包含卵，不能直接当成新增活虫数。

### 三条没有对应剧情函数的候选组合

1. **清理一个位置，反而让另一处形成窝，又重新占回原处（C）。** 12 秒药剂信号生效；30–172 秒发生五次剂量死亡，其余个体逐步迁往 Archive。138 秒 Archive 成巢，420 秒首窝卵孵化，422 秒有新一代迁回 Downloads，504 秒原位置也形成窝。代码没有 ChemicalCreatesNest 或 RecolonizeAfterCleaning：是残留衰减、偏好、拥挤、繁殖及迁移共同作用。部分迁移在喷药前 10 秒就开始，来自初始拥挤，不能把所有迁移归因于药剂。

2. **常用位置驱赶住客，安静窝繁殖后的外出暴露了窝（A）。** 原始八只在 2–20 秒离开 Downloads；272 秒 Archive 成巢，454／456 秒孵化两窝卵，458 秒出现迁移及首次 exposed。暴露本身是明确规则，因哪个家庭何时繁殖、何时挤出去而出现，则没有独立脚本。30 分钟结束时仍有两只位于 Downloads，说明偏好是竞争而非绝对禁区。

3. **同一个地方既是食物来源又是危险来源，出现反复离开与返回（F）。** Archive 每 120 秒投喂、每 900 秒喷药；902 秒有多只迁出，之后在环境变化时返回，2 小时累计 251 次迁移、20 次死亡。不是写了“喷药后返回 N 次”，而是吸引力、药剂与局部竞争反复改变相对分数。它是规则互动，也暴露了可能过度往返的问题，不能把次数多包装成好玩。

### 生命周期对照

D 初始六只成虫与两窝卵：喷药后先死四只，120 秒输入手动清除剩余成虫，122 秒处理完成；354 秒两窝卵孵化，之后幼体分散并在 Archive 成巢。相同动作去掉初始卵后，30 分钟末人口为 0、没有出生；空世界运行两小时也没有神秘访客或补怪。这支持“回归来自幸存卵”的因果判断。

E 在 2 秒相同扰动下，胆小个体选择 flee 并迁移，胆大个体选择 freeze，到 30 秒才迁移。状态确实能分化选择，但这仍是直接 utility 规则证据，不单独称为涌现故事。

以上是可重复的规则组合候选，尚不等于真实玩家能察觉或愿意分享的故事。选定场景原始摘要见 [evidence.json](emergent-world-v0-evidence.json)；完整日志通过测试脚本生成在 build/simulation，不包含玩家资料。

## 5. Failed experiments

- 最初把 A 的期望写成“最终常用文件夹零住客”，断言失败：拥挤后两只返回。改为检查前两分钟多数原住客迁出；没有调整参数来强行制造零住客。高频使用降低偏好，不保证灭绝。
- D 最初只喷一次药，且移动冷却 80 秒，六只仅死三只；延长观察／冷却仍有耐受个体存活。无法用它证明卵是唯一恢复来源，所以增加手动清除及无卵对照。没有改成喷药全杀。
- F 的 251 次迁移具有重复振荡，不算成熟的桌面生态节奏；G 后期主要停在容量附近，没有持续产生新颖组合。暂不增加内容掩盖这个问题。
- “用户自然理解巢穴和生态”尚无真人实验依据。当前确认的是模拟因果与兼容流程，不是已经验证卖点。

## 6. Tests

实际执行：

- Swift 优化模型测试：World 默认字段、旧存档个体／名字／伙伴／纸条／成就、无伪造历史、保护对象药剂免伤、PRNG 保存续跑、不复活移除对象、延迟药剂结算一次；既有工具、飞行、经济、收纳、领养、专注、猫爪、鼠标停留测试。
- .NET CoreTests：既有跨平台玩法与上述迁移、药剂、保护、空世界、文件夹只发信号检查。
- `python3 Tests/Simulation/run.py`：A–G 七场景完整状态／事件／样本跨语言比较；同 seed 重跑；Swift 前一小时保存、C# 后一小时续跑与完整 F 一致；无卵／空世界对照。
- Mac 原生 `--integration-test`：真实 AppKit 窗口／图层、工具菜单、最小化恢复、左右键动作原地路由、暂停／专注、文件夹信号、药剂非即时死亡、吸尘后无复活、鼠猫画布、容量。
- Mac arm64 开发构建与 Universal arm64 / x86_64 发布构建；Windows win-x64 自包含发布构建。Windows 模型运行于 Mac，未运行 Windows 原生 GUI。

### 性能实测

使用 `/usr/bin/time -l` 启动隔离原生 Mac 程序、隐藏主面板、持续 30 秒；包含冷启动／退出。不会读取或写入玩家存档，禁用真实 Finder 观察。测量时没有加载大型历史存档。

| 模式 | wall | user + sys CPU | 约占单核 | 峰值 RSS |
| --- | ---: | ---: | ---: | ---: |
| 暂停隐藏 | 31.56 s | 0.24 s | 0.76% | 101.7 MiB |
| 初始两住客、生态启用 | 31.73 s | 0.96 s | 3.03% | 118.3 MiB |

一天 headless 世界计算及日志收集约 0.5–0.8 秒；30 分钟约 5–40 毫秒，语言与运行批次有差异。这不是满屏动画、Intel 或 Windows 的功耗结论。暂停仍有原生定时器唤醒；活跃模式大部分成本来自现有渲染，尚未优化到事件驱动的完全静止窗口。

## 7. Known issues

- 两份模拟源码需要持续执行 parity 测试；跨架构浮点数完全逐位相同尚未在 Intel / Windows 真机验证。
- 位置是最多 64 个观察过的匿名栖息地；不扫描未访问文件夹，超过预算的信号回落到桌面。没有真实文件垃圾量或语义检测。
- 药剂距离是个体持久化的抽象暴露距离，不是每个像素的物理流体。孵化与成巢参数属首轮实验值。
- 过量迁移、容量饱和、稀有访客与黄金出现的长期节奏仍需平衡；清空全部卵与住客后可能真正归零。没有强制“好玩”的救场脚本。
- 普通渲染路径和明确玩家操作仍经过兼容 Resident；世界记录／投影已经接通，但不是全项目所有功能都改成同一个状态结构。Life 的内部关系门槛仍存在，只取消了外显计数。
- 桌面演示不是预定章节；某些因果链可能错过。静态卵沿用当前图层，巢穴沿用碎屑入口，没有新增窝动画。
- 本轮没有 Windows / Intel 真机，也没有外部 UI 自动化完成真实 Finder／Explorer 授权后端到端验收。Mac 测试是程序自身原生组件与动作路由验收。
- 近期事件只保留 512 条；完整生态复现请保留 seed、初始快照和输入动作。日常存档是 30 秒合并写入，正常退出立即保存。

## 8. Next smallest experiment

只测试一个变化：**迁移选择加入更强的目的地优势滞后**。固定 F 的食物／药剂动作，比较当前与一个更高优势差值，在同一组种子上统计往返次数、存活与巢穴数，再看桌面录像是否减少机械折返。不要先增加新的动物或事件。
