## 现状盘点

现在玩家要接触的概念和入口有 **20 多个**，分散在 5 个地方：

| 位置 | 内容 |
| --- | --- |
| 主面板（620×420 的窗口） | 标题、一段教程文案、角色插画、5 个工具（带价格）、金壳余额、工具说明、喂一点、去桌面玩、我的小窝、歇一会儿、状态句 |
| 「···」与菜单栏菜单 | 当前工具、金壳、撒点面包屑 +3、收起蟑螂药、清理游戏痕迹、试玩文件夹、连接 Finder、生长速度（3 档）、我的小窝、退出 |
| 我的小窝（4 页） | 伙伴：下拉选择、出来玩、分享这位朋友、开关安全窝、安排共居、接朋友入住。纸条：收好、取回、完成 / 撤销、删除。专注：开始、结束。成就：22 张卡 |
| 右键菜单 | 摸一摸、喂一口、起名字、成为伙伴、收下黄金卵壳、去右边巡逻、放它去玩 |
| 桌面上 | 住客、卵、尸体、污渍、药剂泡沫、碎屑、空壳、猫爪、老鼠、气泡 |

问题：

- **主面板像说明书**：一半面积是教程文字。玩家还没开始玩，先要读三行说明。
- **同一件事有多个入口**：喂食同时出现在面板、菜单（面包屑）和右键菜单；小窝也有三个入口；「歇一会儿」和「专注」是两套相似的暂停。
- **和核心玩法无关的功能占了一半**：纸条、安全窝、共居、巡逻、分享 / 领养码、试玩文件夹、生长速度。它们来自早期设计草案，平均每个玩家很少用到，却每次都摆在眼前。
- **一上来就全部摊开**：5 个工具连同价格一开始就全部显示，新玩家看不懂「金壳」是什么、为什么要攒。

## 原则

1. **桌面就是游戏。** 玩发生在桌面上，面板只是遥控器，小而安静。
2. **一件事一个入口，一个名字。**
3. **用到才出现。** 新玩家只看到「捏一下」和「喂一点」。金壳第一次到手时，才出现「工具」；第一次有住客被命名时，才出现「住客」页。
4. **用画面说话，少用文字。** 状态尽量由桌面上的东西表达（卵、碎屑、泡沫），不写说明句。文字只用在日报里讲故事。
5. **默认安静。** 没有红点、角标、倒计时，不催玩家。（呼应 D6 不打扰。）

## 方案

### 1. 主面板 → 菜单栏小弹窗

点菜单栏图标（Windows 是托盘图标），弹出一个约 300 宽的小弹窗，替代现在的大窗口：

```
┌──────────────────────────────┐
│ 🪳 角落里有 7 位住客           ⚙ │  ← 一句话状态
│ 「下载文件夹的老家族孵出了 3 只」 │  ← 最新一条日报（有才显示）
│                                │
│  [✋] [🩴] [💨]        ✦ 12     │  ← 只显示已拥有的工具 + 金壳
│                                │
│  [ 喂一点 ]  [ 勿扰 ○ ]          │
│                                │
│  小窝 ›                         │
└──────────────────────────────┘
```

- 去掉教程文案和大插画。第一次打开时，在桌面上让一只住客探出头来，比读说明更直观。
- 「去桌面玩」不再需要：弹窗点外面就收起。
- 「歇一会儿」和「专注」合并为一个 **勿扰** 开关。D6 的自动「忙时藏」做好后，它就是手动版的同一件事。

### 2. 工具：只显示已拥有的

- 一开始只有「捏一下」，工具栏甚至可以不显示。
- 第一次拿到金壳时，弹窗底部出现「✦ 可以换新工具了」，点开是一个小商店，显示还没换的工具和价格。
- 已拥有的工具只显示图标，悬停显示名字。

### 3. 小窝：4 页 → 3 页

| 页 | 内容 | 出现时机 |
| --- | --- | --- |
| **日报** | 忙时发生的事（P2） | 有第一条日报时 |
| **住客** | 起过名字的、成为伙伴的；以后加家谱（P3） | 第一次起名时 |
| **收集** | 成就和图鉴合在一起 | 获得第一个成就时 |

- 默认打开日报页。

### 4. 右键菜单：最多 4 项

按对象只显示能做的事：

- 普通住客：摸一摸、喂一口、起名字
- 已命名：摸一摸、喂一口、成为伙伴
- 黄金住客：多一项「收下金壳」
- 猫鼠：摸一摸、喂一口

去掉「放它去玩」（点菜单外面就是放它去玩）。

### 5. 设置（⚙）

收纳不常用但需要保留的东西：

- 日报时机：从忙转闲时（默认）、每天固定时间、只在打开小窝时（D9）
- 连接 Finder / 资源管理器
- 生长速度
- 清理游戏痕迹
- 隐私说明
- 退出

### 6. 暂时收起的功能（需要你确认）

下列功能和核心玩法关系弱，建议**从界面上收起，但保留数据和代码**，以后有合适的位置再放回来：

| 功能 | 建议 | 理由 |
| --- | --- | --- |
| 纸条 / 收纳 | 收起 | 是效率工具，不是游戏；和「桌面小世界」无关 |
| 专注计时器 | 并入「勿扰」 | 自动「忙时藏」会覆盖它的目的 |
| 安全窝、安排共居、去右边巡逻 | 收起 | 概念多、解释成本高；以后可以用「小摆设」（P4）更直观地实现 |
| 分享 / 接朋友入住（领养码） | 收起，P5 时回归 | 需要先有个体差异（P3）才有交换的意义 |
| 试玩文件夹 | 移入设置的开发者选项 | 是演示 / 测试用 |
| 撒点面包屑（菜单） | 删除 | 和「喂一点」重复 |

## 验证

- 记录他们第一次犹豫或发问的地方。
