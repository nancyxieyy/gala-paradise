## 背景

现在玩家要面对 20 多个概念和入口：主面板一半是教程文字，同一件事有多个入口，半数功能和核心玩法无关。负责人确认的方向是：**桌面就是游戏，面板只是遥控器；用到才出现；一件事一个入口；少用文字。**

本任务只改界面的组织方式，**不改生态规则**（`World` 的规则不动，`diff_base.py` 必须 identical）。唯一的例外是第 3 条「勿扰」，见下文。

## 要做（双端：Mac AppKit / Windows WinForms）

### 1. 主面板 → 菜单栏 / 托盘小弹窗

- Mac：点菜单栏图标弹出 `NSPopover`（宽约 320）。现在的 `Dashboard` 大窗口不再作为主入口，App 不显示 Dock 图标（`.accessory`）。
- Windows：左键点托盘图标，在托盘附近弹出一个无边框小窗口，点外面自动收起。右键托盘只保留「打开」「退出」。
- 弹窗内容从上到下：
  1. **状态行**：「角落里有 N 位住客」，N 为活体数（adult、baby、gold）；为 0 时显示「角落里很安静」。右侧放设置按钮（⚙）。
  2. **工具行**（满足出现条件才显示，见第 2 节）：已拥有的工具只显示图标，当前工具高亮，悬停显示名字。右侧是金壳余额加「换工具」入口。
  3. **两个按钮**：「喂一点」（主按钮）、「勿扰」（开关）。
  4. **底部「小窝 ›」**：满足出现条件才显示。
- 去掉：教程文案、大插画、「去桌面玩」「歇一会儿」按钮、工具说明句、底部状态句。

### 2. 用到才出现（全部由现有状态推导，不新增「教程进度」字段）

| 元素 | 出现条件 |
| --- | --- |
| 工具行 | 拥有不止一个工具，或金壳余额 > 0 |
| 「换工具」商店 | 同上；点开后列出未拥有的工具和价格，沿用现有的兑换逻辑 |
| 小窝入口 | 「住客」或「收集」页至少有一项内容 |
| 小窝「住客」页 | 至少一位住客被命名或成为伙伴 |
| 小窝「收集」页 | 至少获得一张成就卡 |

新存档打开时，弹窗里只有状态行、「喂一点」和「勿扰」。

### 3. 「勿扰」合并「歇一会儿」和「专注」

- 开启后：桌面上的住客全部隐藏，不会有新的住客出现在桌面上；**生态照常运行**，不再暂停。这是为 D6「忙时藏、闲时出」铺路；自动判断忙碌在任务 005 实现，本任务只做手动开关。
- 关闭后：住客按现有的可见预算陆续出现，不要一次全部弹出来。
- 原来的专注计时器从界面收起。已获得的「专注完成」类成就保留，不再新发。
- 这是本任务唯一改变生态运行的地方：勿扰期间，生态时间继续推进，原来专注期间是暂停的。在实现记录里写明对 `diff_base.py` 的影响。预期是没有影响，因为模拟场景不经过界面开关；如果有影响，解释原因。
- 旧存档如果停在专注或暂停状态，读档后一律恢复为正常状态。

### 4. 小窝：两页（日报页在任务 006 加入）

- 「住客」：已命名、已成为伙伴的住客；保留「叫它出来」。去掉下拉框之外的复杂操作（见第 6 节）。
- 「收集」：现有的 22 张成就卡。
- 只有一页有内容时，不显示分页控件。

### 5. 右键菜单：最多 4 项，按对象显示

- 普通住客：摸一摸、喂一口、起个名字…
- 已命名的住客：摸一摸、喂一口、成为伙伴
- 黄金住客：在上面的基础上多一项「收下金壳」
- 猫、鼠：摸一摸、喂一口
- 菜单顶部可以有一行灰字（例如「一只小旮杂 · 有点胆小」），不可点。
- 去掉「放它去玩」：点菜单外面就是放它去玩。

### 6. 收起边缘功能（只去掉界面入口，保留数据和代码，旧存档照常读写）

纸条 / 收纳、专注计时器、安全窝、安排共居、去右边巡逻、分享这位朋友、接朋友入住（领养码）、菜单里的「撒点面包屑」（与「喂一点」重复，直接删掉入口）。

- 清理游戏痕迹
