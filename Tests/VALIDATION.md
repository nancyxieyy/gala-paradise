- Mac：分别交叉编译 arm64 / x86_64，lipo 确認通用二进制包含两个架构；本机 arm64 模型与原生集成测试通过。Intel 真机未运行。
- Windows：使用微软官方 .NET SDK 10.0.401（下载后校验 SHA-512），WinForms 项目交叉发布为 win-x64 自包含单文件 GUI EXE。编译无错误／警告；PE 文件架构与嵌入图标资源已核对。
- Windows 玩法模型：在 Mac 的 .NET 主机上运行通过 21 项检查，覆盖锁定、飞行、污渍、四类吸尘对象、投药留卵、孵化、存档、边缘出现／退出、隐藏间隔、专注、暂停、漏网之鱼与数量上限。
- Windows 原生托盘、透明分层窗口、资源管理器与 DPI 行为：当前无 Windows 主机，未实机执行。提供 --smoke-test 与手动 Windows CI 工作流；它们尚未在 Windows 上运行，不把交叉编译等同于 GUI 验收。
- 朋友包不含开发者存档。当前无发行证书，Mac 未公证、Windows 未签名。

## 1.4.1 圆耳鼠形象

两端老鼠采用暖灰色圆身、粉耳、大白眼与粗轮廓；桌面画布尺寸 170，透明窗口扩至 182，出入屏幕位置随窗口尺寸计算。Mac 原生集成测试确认实际内容视图容纳放大角色，现有玩法测试通过；已用程序自身绘图导出并检查角色预览。Mac 通用包及 Windows x64 包构建成功，Windows 模型测试通过，Windows 原生显示仍待真机验证。

## 1.4.3 胡须与落地猫爪

老鼠胡须改为脸颊下方三条细线，避开鼻子与眼睛。猫爪改为爪背朝上、连着屏幕外前腿的形象，尺寸 240，使用六秒伸入／落地停留／抬起收回动画。Mac 与 Windows 模型测试验证接触曲线、停留位置固定以及结束后移除；Mac 原生集成测试通过。程序自身渲染预览已检查，两端发行包构建通过；Windows 原生动画尚待真机确认。
